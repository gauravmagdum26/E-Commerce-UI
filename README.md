# Quick Kart 🛒

A responsive and interactive frontend web application for a modern e-commerce platform.
## 🚀 Features

* **Dynamic Product Display:** Engaging UI for viewing product catalogs.
* **Responsive Design:** Fully optimized layout that provides a smooth shopping experience across desktop.
* **Category Filtering:** Easy-to-use navigation and filtering options to help users find specific products quickly.
* **Modern UI/UX:** Clean aesthetics with intuitive hover effects and transitions.

## 🛠️ Tech Stack

* **Frontend:** HTML5
* **Styling:** CSS
* **Scripting:** JavaScript (ES6+)
* **Version Control:** Git & GitHub
